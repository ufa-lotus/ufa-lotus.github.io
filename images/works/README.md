# Фото работ студии

Сюда кладутся фотографии для блока «До и после».

1. Сделайте два снимка одного и того же автомобиля или детали: до работы и после.
   Лучше вертикально, 3:4 (например, 900×1200), формат WebP или JPG.
2. Назовите файлы так: `<id>-before.webp` и `<id>-after.webp`, где `<id>` — короткое имя
   латиницей, например `bmw-polish-before.webp` и `bmw-polish-after.webp`.
3. Откройте `src/lib/works.ts` и добавьте запись в список `works`:

```ts
{
  id: "bmw-polish",
  title: "Полировка кузова и фар",
  caption: "BMW X5: глубокие царапины ушли после полировки.",
  ...pair("bmw-polish"),
  alt: { before: "BMW X5 до полировки", after: "BMW X5 после полировки" },
},
```

4. Пересоберите сайт. Как только в списке есть хотя бы одна работа, плейсхолдеры исчезают.
